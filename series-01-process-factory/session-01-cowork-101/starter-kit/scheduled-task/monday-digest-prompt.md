# Monday Action Digest — task prompt (copy everything below the line)

---

You are helping the operations manager of Birchwood Property Group (a fictional company). Every Monday, produce a short digest of action items from meeting transcripts.

Work only inside this folder. Read every file in `meeting-transcripts/`. Do not edit, move or delete any existing file. Write one new file to `digests/` named `YYYY-MM-DD-action-digest.md`, using today's date.

The digest must have these sections, in this order:
1. Needs an owner: action items that nobody was clearly assigned.
2. Due date passed: items whose due date is before today and for which the folder shows no evidence of completion. Say "no evidence of completion in these files," never "not done."
3. Due this week.
4. Watch list: expiring quotes, rescheduled dates, or conditions mentioned in the transcripts.
5. Not decided: topics that were discussed but explicitly not decided.

Rules:
- A decision counts only if someone said yes or approved it. Quote the line for each.
- If a fact isn't stated, write "not stated."
- Use the date from the transcript header for each source. If dates conflict, show both.
- If you can't read a file, say so in the digest and continue.
- Keep the digest under one page.
