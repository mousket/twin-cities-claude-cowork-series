1The short version

  1. Download birchwood-starter-kit.zip from Google Drive (or GitHub).
  2. Unzip it into a simple folder like Documents. Use “extract”, not “open the zip”.
  3. Check that you can see a folder called birchwood-folder with 20 files in it.
  4. Stop there. Read START-HERE.md if you like, but don't run the prompts. We do those together, and the exercises work best if you haven't peeked.

When in doubt, use Google Drive.

3Route A: Google Drive

Open the Google Drive link

  1. Open the link above and download birchwood-starter-kit.zip (the download arrow at the top of the preview, or right-click and Download). It is small, a few dozen KB, so it should take a moment.
  2. Move the zip out of Downloads into Documents, if you like. Anywhere simple works.
  3. Unzip it.
    Mac

    Double-click the zip. A folder called birchwood-starter-kit appears next to it.

    Windows

    Right-click the zip and choose Extract All…, then Extract. Don't just double-click and browse inside the zip; files in there are a preview and can't be changed.

  4. Open the new folder and carry on to Check it.

4Route B: GitHub

Open the GitHub repository

B1. Download ZIP (no tools needed)

  1. On the repository page, choose the green Code button, then Download ZIP. Unzip it.
  2. Open: series-01-process-factory → session-01-cowork-101 → synthetic-data → property-management → inputs.
  3. That inputs folder is the kit's birchwood-folder. Copy it to somewhere simple, such as Documents, and rename the copy birchwood-folder.
  4. The prompts live in session-01-cowork-101/starter-kit/prompts.

B2. Clone and build the same zip (developers)

git clone REPO-URL-FROM-THE-GITHUB-PAGE cowork-seminars
cd cowork-seminars
python3 scripts/make_kit.py

That writes birchwood-starter-kit.zip in the repo's top folder. Unzip it as in Route A. On Windows, use py instead of python3 if that's how Python is installed.

Note

Before the session, the repository may hold only the attendee material. Instructor notes and answer keys are published afterward.

5Check you have the right thing

After unzipping, you should see this. The highlighted folder is the one we use.

birchwood-starter-kit/ ├── START-HERE.md ├── before-you-come/ (these two guides) ├── prompts/ (what to type on Tuesday; don't run yet) └── birchwood-folder/ ← connect THIS folder to Cowork ├── data/ (rent roll, action tracker) ├── digests/ (empty; Cowork writes here) ├── docs/ (leases, notes, policies, vendors) └── meeting-transcripts/ (3 files)
RightYou connect birchwood-folder, which contains docs, data, meeting-transcripts and digests.
WrongYou connect Documents, Downloads, Desktop, or even the whole birchwood-starter-kit folder.

Count the files (optional, 30 seconds)

The folder should have 20 files and 3 transcripts.

Mac (Terminal)
cd ~/Documents/birchwood-starter-kit
find birchwood-folder -type f | wc -l
ls birchwood-folder/meeting-transcripts
Windows (PowerShell)
cd "$HOME\Documents\birchwood-starter-kit"
(Get-ChildItem birchwood-folder -Recurse -File).Count
dir birchwood-folder\meeting-transcripts

Adjust the path if you put the kit somewhere other than Documents. A different count usually means a partial download or that you're looking at the zip's preview; re-download and extract again.

6Where to keep it

  • A simple local folder such as Documents is easiest. Avoid burying it deep inside other folders.
  • Your computer may ask for permission the first time Claude reaches a folder like Documents. Allow it for what you need, no more.
  • This folder is disposable. Cowork may create files in digests/, and later exercises can add files elsewhere. Nothing here is real.

8Starting over

If a file is changed, deleted or confusing, delete the birchwood-starter-kit folder and unzip the original zip again. Nothing is lost that you can't recreate in a minute.

9Trouble

Google Drive says I need access, or the download is blocked
  • Try opening the link in a private window, or on your phone and sending the file to yourself.
  • Company networks sometimes block Drive. Try your phone's hotspot.
  • Tell a helper at the door on Tuesday and we'll get you a copy.
The zip won't open or says it's damaged
  • Download it again. If your browser saved it twice, use the newest copy.
  • The file should be a few dozen KB. A file of only a few KB is probably a web page, not the zip.
I see the files but they look strange on Windows
  • Make sure you used Extract All… and are working from the extracted folder, not the zip.
  • Open .txt, .md and .csv files in a text editor; Excel will happily open .csv files but isn't needed.
I have a different folder structure than the picture

That's fine as long as there is a folder called birchwood-folder with docs, data, meeting-transcripts and digests inside. Bring a screenshot to a helper if in doubt.

My work laptop won't let me use it

Don't work around your employer's settings. Pair with a neighbor on Tuesday. You can run the kit at home later.
