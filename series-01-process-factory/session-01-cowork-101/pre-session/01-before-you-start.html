What you need

Sorted by how much it matters. Only the first group is needed to run every step yourself.

Required to work hands-on

RequiredInternet connection

Anthropic says an active internet connection is required throughout a Cowork session. You also need it to download the kit. Venue Wi-Fi can be slow, so have your phone's hotspot as a backup.

RequiredA Mac or Windows computer

Laptop or desktop. Mac needs macOS 11 or newer. Windows needs Windows 10 or newer. Phones and tablets are fine for watching and reading, not for the folder work.

RequiredA web browser

Any current one (Chrome, Edge, Safari or Firefox). You use it for these guides, your Claude account, and the GitHub or Google Drive download page.

RequiredA paid Claude plan

Pro, Max, Team or Enterprise. Cowork is not included on the Free plan. Your Claude account is the one you sign in with at claude.ai.

RequiredThe Claude desktop app

Free to download at claude.ai/download, and it needs to be up to date. Cowork lives inside it, in the message box. Tasks that use files on your computer need the app open.

Does the free version of Claude work for this?

Not for the hands-on parts. Cowork, which is what we use to give Claude a folder (Part 1) and to run a task on a schedule (Part 3), is available only on paid plans. On the Free plan you can still read every guide, download the kit, and watch the session. You can also try the skill behind Part 2: paste one of the meeting transcripts into an ordinary Claude chat, then ask the same questions and check the answers the same way. Free usage limits apply, and it won't give you the folder or scheduling experience.

Strongly recommended

RecommendedVS Code (free)

A free code editor from code.visualstudio.com. Cowork doesn't need it. You use it to look at what's in the kit and what Claude creates: Markdown, CSV and text files, with colors, search and a side-by-side preview. Open the whole birchwood-folder with File, then Open Folder. Press Ctrl+Shift+V (Cmd+Shift+V on Mac) on a Markdown file to see it formatted. Any text editor works if you prefer.

RecommendedA GitHub account

Free at github.com. You don't need one to download the kit, because the repository is public. With one you can follow the repository for each new session, copy it with a clone or fork, and open an issue when something is unclear.

RecommendedA Google account for Drive

The same kit is on Google Drive as a backup route. You may be able to download without signing in, but Drive can ask you to. If you already use Gmail, you have one.

Good to know

  • A tool to unzip files. Windows and macOS both have one built in. You don't need to install anything.
  • Disk space. The kit is well under 1 MB. You'll need a few MB free in total.
  • Git, optional. Only if you'd rather clone the repository than download the zip. The kit page shows both ways.
  • Either GitHub or Google Drive is enough. They deliver the same zip. Having both accounts just gives you a backup.

The 3-minute practice test

This proves three things at once: your plan works, Cowork opens, and Cowork can work in a folder you choose. It uses a throwaway folder, not the starter kit and not any real files.

  1. Make an empty folder named cowork-practice somewhere simple, such as Documents.
  2. Open the Claude desktop app, and in the message box select Cowork.
  3. Choose cowork-practice as the folder to work in. The control for choosing a folder may be labeled differently in your version, and your operating system may ask for permission. If you can't find it, write down what you see and ask in the meetup.
  4. Paste this request into the Cowork message box.
    Paste into Cowork
    Create a text file named hello.txt in this folder. It should say "Cowork works" and today's date. Then tell me the file name.

    Button not working? Select the text above, then copy it with Ctrl+C (Cmd+C on a Mac).

  5. Look in the folder. You should see hello.txt. Cowork may ask you to approve the action first. Approving is fine for this practice folder only.
Success

You see hello.txt in the practice folder. You're ready.

More detail on installing

  • Go to claude.ai/download and pick your system. Open the downloaded file to finish installing.
  • Launch Claude (Applications on Mac, Start menu on Windows) and sign in with your account.
  • Updates arrive inside the app on Mac and Windows.

Privacy and good habits

Do
  • Use only the birchwood-folder from the kit.
  • Treat the kit as disposable. Re-download it any time.
  • Predict before you press enter. Write down what you think Claude will find.
  • Ask Claude to quote the line that supports an answer.
Don't
  • Connect Documents, Desktop or Downloads as a whole.
  • Put real client, tenant or employee data in the session.
  • Work around your employer's IT or admin settings.
  • Assume an answer is right because it sounds confident.
Why the folder rule matters

The folder you connect is the folder Claude can read and quote. Everything in our kit is made up: Birchwood Property Group, its tenants, vendors and numbers are fictional. That is deliberate, so you can see Cowork work without risking anything real.

What the session looks like

If you're stuck

I don't see “Cowork” in the app
  • Update the Claude desktop app and restart it.
  • Confirm you're on a paid plan and signed in to the right account.
  • On Team or Enterprise, an admin controls availability. Ask them. Don't try to bypass it.
  • Use the desktop app. Anthropic's documentation says tasks that use files on your computer need the desktop app open so Claude can reach them.
I only have the Free plan
  • Cowork isn't available on Free, so you can't run the folder and scheduling parts yourself.
  • Read the guides, download the kit, and follow the session by watching, or paste a transcript into a normal chat to practice Part 2.
  • If you want to run everything, a paid plan is the only way to get Cowork.
I can't choose a folder, or my computer asks for permission
  • Your operating system may ask whether Claude can access a folder. Allow it for your practice folder or the starter kit only.
  • Put the folder somewhere simple, like Documents, and try again.
  • On a managed laptop, IT policy may block it. Bring the question to the session and pair up.
Claude says I've reached a usage limit
  • Cowork tasks use more of your allowance than chatting. Wait for your allowance to reset, or pair up.
  • Avoid heavy Cowork use right before the session.
I can't download the kit at work
  • Some company networks block Google Drive or GitHub. Try the other route, your phone's hotspot, or download it at home.
  • If you're at the live meetup and nothing works, tell a helper at the door. We'll get a copy to you.
The practice test worked but I'm nervous about the real session

That's normal. The kit is fictional, you can't break anything important, and there are helpers in the room. If something goes wrong, we get to see something real about how these tools behave, and that is part of the lesson.

Glossary

CoworkThe mode of Claude's desktop app where Claude works on tasks for you, including in folders you choose.
Folder accessLetting Cowork see files in a folder. Only share folders you're comfortable with Claude reading.
TranscriptA written record of a meeting or call, usually from a recording.
PromptThe instruction you give Claude.
Scheduled taskA saved prompt that Cowork runs on a schedule (hourly, daily, weekly, weekdays) or on demand.
ApprovalCowork can ask your permission before taking an action. A scheduled task has an approval setting too.
Synthetic dataMade-up data that looks real. Everything in our kit is synthetic.
VS CodeVisual Studio Code, a free editor for reading and editing text, code, Markdown and CSV files.
Repository (repo)A project folder hosted on GitHub, including its history and its Releases. Ours is public.
